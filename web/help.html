CADV 是给 M5Stack Cardputer-Adv 用的一组小程序。芯片里只放一个「基座」，程序放在 microSD 卡的 cadv/ 里，开机选一个载入。

第一次装

  1. 关掉电源开关，按住 G0，插上 USB 线，再松开 G0。
  2. 点「基座」后面的「烧录」，在弹出的列表里选这块板子的串口。问要不要清空时，第一次装选清空；只是升级可以不清，设置会留着。
  3. 烧完按一下侧面的 RESET。
  4. 下载「SD 卡程序包」，解压到 microSD 卡根目录（得到一个 cadv 文件夹），插回板子。
  5. 开机后用 , / ; . 选程序，Enter 载入。在程序里按住 Fn+BS 回到基座。

单独烧一个程序

不想要基座、只用一个程序时，在首页「单独烧一个程序」里点它。这会盖掉芯片里原来的东西；想回到基座，再烧一次基座就行。

烧不进去

只能用电脑上的 Chrome 或 Edge，手机和 Safari、Firefox 都不支持 Web Serial。

列表里没有串口：确认是按住 G0 再插的线，换一根能传数据的 USB 线。

烧完屏幕不亮：按一下 RESET，或关电源再开。

烧录用的是 ESP Web Tools。源码和说明：github.com/vvenv/cadv。
