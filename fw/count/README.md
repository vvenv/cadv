# 计数

Casio 三行面：标题 / 七段大数字 / 步长。**M** 选模式：

| 模式 | 怎么加一 |
|------|----------|
| **手动** | Enter / 空格 |
| **听响 · 高/中/低** | Enter 开听后，麦克听到一声响就加；再按 Enter 停听 |

听响时喇叭关掉（和麦克共用 I2S），只靠屏幕闪一下。灵敏档也可在听声界面按 **S** 切换。两种模式都能 BS 减、K/J 改步长、连按两次 R 清零。模式、灵敏、数值、步长会记住。

```bash
./do.sh sim count
./do.sh sd fw count
```
