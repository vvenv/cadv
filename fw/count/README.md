# 计数

Casio 三行面：标题 / 七段大数字 / 步长。**M** 选模式：

| 模式 | 怎么加一 |
|------|----------|
| **手动** | Enter / 空格 |
| **听响 · 高/中/低** | Enter 开听后，麦克听到一声响就加；再按 Enter 停听 |

听响认的是**短促清脆的一下**（球拍打带子、拍手、敲击），不认慢慢变响的声音：挥拍的风声、说话、风扇都不算。做法在 C 里（`onset.c`）：先滤掉 1 kHz 以下，每 4 毫秒算一次能量；比环境底噪高出一截、并且 8 毫秒内猛跳上来才算候选，再看 12 毫秒内是不是已经回落（风声会一直往上涨），才加一。加一之后要等声音落下去 8 dB、且隔够 0.18 秒才认下一下，带子的余振和回声不会重复算。底噪一直在慢慢跟，环境变吵也不会卡住。灵敏「低」只认离得近、够响的，旁边有人一起练时用它。

听响时喇叭关掉（和麦克共用 I2S），只靠屏幕闪一下。灵敏档也可在听声界面按 **S** 切换。两种模式都能 BS 减、K/J 改步长、连按两次 R 清零。模式、灵敏、数值、步长会记住。

```bash
./do.sh sim count
./do.sh sd fw count
```
