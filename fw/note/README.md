# 记事

笔记存在卡上 `cadv/note/*.txt`（`cadv/` 本身放固件和标签，记事不碰）。旧版放在 `cadv/` 下的编号笔记（如 `001.txt`）打开时自动移进来。

- 列表：每条显示首行，右侧是编号，新的在上。`N` 新建，`Enter` 打开，连按两次 `D` 删除。
- 编辑：光标处输入；`Fn+H/L` 左右、`Fn+K/J` 上下移光标；`BS` 删光标前一字；按住会连发。屏幕随光标滚动，右侧有滚动条。
- 保存：停手约 3 秒自动存，`Fn+``（Esc）返回或 `Fn+BS` 回基座时也会存；标题后的 `*` 表示还没存。先写临时文件再改名，写到一半拔卡不会毁掉原笔记。
- 超过 4000 字节或含无法还原字符（如 emoji）的文本不进入编辑。
- 编辑中 `Q` 是字母。`Fn+Q` 把不超过 17 字节的内容画成二维码，空笔记提示「空」。

```bash
./do.sh sim note
./do.sh sd fw note
```
