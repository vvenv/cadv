# 摩斯

喇叭发摩斯电码，板载灯跟着闪。**Tab** 在两种模式间切换。

- **发报**：打字母或数字，按顺序发出去。屏幕中间是正在发的字和它的点划，底下一行是打过的字，已发的亮、待发的暗。空格是词间停顿，BS 删掉还没发的字，Esc 停下并清空。
- **抄收**：按 Koch 法练听。机器发一个字，你打出来。对了自动下一个，错了显示答案，Enter 再听或继续。从 K、M 两个字开始，`,` `/` 减少或增加字数（最多 36 个：26 个字母加 10 个数字）。标题栏是最近 20 次的正确率。

**Fn+K/J** 调速度（5–30 WPM，按 PARIS 计时），`-` `=` 调音量。只收字母和数字，标点键留给音量、导航和帮助。速度、字数、音量都会记住。

```bash
./do.sh sim morse
./do.sh sd fw morse
```
