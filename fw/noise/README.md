# 助眠

喇叭放持续的背景声，带定时关闭。声音是板子上实时合成的，不用 SD 卡，也不会循环出接缝。

| 声音 | 听起来 |
|------|--------|
| 白噪音 | 均匀的沙沙声 |
| 粉红噪音 | 比白噪音柔，像远处的瀑布 |
| 褐噪音 | 低沉，像飞机舱里 |
| 雨声 | 柔和的底噪加零星雨点 |
| 海浪 | 一阵一阵涨落，每阵 7–11 秒 |

K/J 选声音，Enter 播放或停止，`,` `/` 改定时（15、30、60、90 分钟，或不关），`-` `=` 调音量。最后 30 秒慢慢变小再停。标题栏显示剩余时间。30 秒不动会熄屏，声音照放。声音、定时和音量都会记住。

```bash
./do.sh sim noise   # 桌面没有喇叭，只能看界面
./do.sh sd fw noise
```
