# 分贝

用麦克风测环境声级。中间大数字是当前值（每 1/8 秒算一次均方根，再做平滑），标题栏右边是这一段时间的平均值（等效声级，按能量平均）和最大值，底下是最近约 19 秒的走势：超过 70 显示琥珀色，超过 85 显示红色。

读数**没有校准**，只能做相对比较。默认零点是「满量程 = 100 dB」。手边有声级计时，对着同一个声源用 `,` `/` 调到读数一致，0 恢复默认；调好的值会记住。Enter 暂停读数，R 清空统计。

麦克风在键盘一侧，测的时候别挡住。空闲时屏幕只调暗，不熄灭，方便放着看。

```bash
./do.sh sim db
./do.sh sd fw db
```
