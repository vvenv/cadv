# 分贝

用麦克风测环境声级。中间大数字是当前值，默认 **A 计权、快档**（时间常数 0.125 秒，按 IEC 61672 的做法在能量上做指数平均）。标题栏右边是这一段时间的平均值（等效声级，按能量平均）和最大值（计权后的最大值），底下是最近约 19 秒的走势，每根柱子是那 1/4 秒的等效声级：超过 70 显示琥珀色，超过 85 显示红色。

`A` 切换 A / Z 计权（Z 只滤掉 20 Hz 以下），`S` 切换快 / 慢（慢档 1 秒，读数更稳）。切换后统计会清空，设置会记住。开机和暂停恢复后的前半秒不计入，避开麦克风上电的爆音。滤波和平均都在 C 里做（`slm.c`），JS 每 1/8 秒只处理一次结果。

读数**没有校准**，只能做相对比较。默认零点是「满量程 = 100 dB」。手边有声级计时，对着同一个声源用 `,` `/` 调到读数一致，0 恢复默认；调好的值会记住。Enter 暂停读数，连按两次 R 清空统计。

麦克风在键盘一侧，测的时候别挡住。空闲时屏幕只调暗，不熄灭，方便放着看。

```bash
./do.sh sim db
./do.sh sd fw db
```
