# 计算

四则、百分、正负、十六进制、温度里程重量换算，以及一串随机字符。结果只显示在本机。

键帽上的符号就是运算。`/` 在这里是除，帮助仍是 `?`。`=` 或 Enter 等于，BS 删一格。加号是 **Shift+=**，乘号是 **Shift+8**，也可以直接按 **X**。绿条上面那一行是还没算完的式子。

**H** 在十进制和十六进制之间切换，屏幕上的数跟着换。正在输入十六进制时 **C** 是数字；开头要打出 C，先按 **0**。没在输入时 **C** 清除，**Esc** 清除并回到十进制。

| 键 | 作用 |
|----|------|
| **0-9** **.** | 输入 |
| **+** **-** **\*** **/** | 四则。`*` 也可用 **X** |
| **=** / **Enter** | 等于 |
| **BS** | 退格。删光第二个数会回到运算符；再按一次取消运算符 |
| **%** | 百分。`200 + 10 %` 是 220 |
| **N** | 正负 |
| **H** | 切换进制 |
| **U** | 下一种单位，作用在屏幕上的数。再按 **BS** 取消 |
| **G** | 随机串 |
| **C** | 清除。十六进制输入途中 **C** 是数字 |
| **Esc** | 清除，并回到十进制 |
| **?** | 帮助 |
| **Fn+BS** | 回启动器 |
