# 打字

用 Cardputer 的小键盘练打字。一轮 4 行，第一个键按下开始计时，打完显示速度（WPM，按 5 个字符算一个词，只算打对的）、正确率和这一轮打错最多的键。

**Tab** 换题目：

| 题目 | 内容 |
|------|------|
| 单词 | 常用英文单词，随机排 |
| 句子 | 短句和全字母句，带大小写和标点 |
| 键位 | 中排 `asdfghjkl;` 和两手交替的字母组合，先找键位 |

打错的字标红，可以 BS 改，也可以接着打（成绩会算进去）。Esc 重来这一轮，看完成绩按 Enter 开始下一轮。每种题目的最好成绩会记住。题目里没有 `?`，按 `?` 是帮助。

```bash
./do.sh sim type
./do.sh sd fw type
```
