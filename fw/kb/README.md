# 键盘

把 Cardputer-Adv 变成手机或 Mac 的键盘。芯片是 ESP32-S3，只有低功耗蓝牙，没有经典蓝牙。对方在系统蓝牙列表里连接，名字是 **CADV KB**。

按键原样发出去。板子上印的是美式键盘；对方如果用别的布局，字符按对方的布局来。本机不拦截普通按键。**Fn+[`** / **Fn+]** 只调本机背光，不发给对方。30 秒不动就熄屏；把屏唤醒的那下键仍然会发出去。

| 键 | 作用 |
|----|------|
| 字母、数字、符号 | 发给对方 |
| **Shift / Ctrl / Alt** | 修饰键 |
| **Opt** | Mac 的 ⌘。板子上已经有 Alt |
| **Fn+`** | Esc |
| **Fn+H / J / K / L** | ← ↓ ↑ → |
| **Fn+, / . / ; / /** | ← ↓ ↑ →（照键帽上印的箭头） |
| **Fn+1** 到 **Fn+=** | F1-F12（`1` 是 F1，`0` 是 F10，`-` F11，`=` F12） |
| **Fn+U / O** | Home / End |
| **Fn+I / N** | 上页 / 下页 |
| **Fn+P** | Delete |
| **Fn+[`** / **Fn+]** | 本机背光。不发给对方 |
| **Fn+空格** | 本机帮助。帮助开着时按键不发给对方，**BS** 关掉 |
| **Fn+Tab** | 清除本机配对并重启。手机或 Mac 上也要忘掉 CADV KB，再连一次 |
| **Fn+BS** | 回基座 |

配对不用密码。系统弹出确认就点配对。一次只连一台。换手机或 Mac 时，先在正在用的那台断开，再连下一台。连上之后顶栏是「已连接」。对方按了 Caps Lock，顶栏会多一个 Caps。

屏中间是刚发出去的字符。还没连上时，按键只显示在屏上，不会发给任何人。

```bash
./do.sh sd fw kb
./do.sh sim kb
```

`sim` 没有蓝牙，只能看界面。`?` 打开帮助。
