# 水平
<!-- summary: 气泡水平仪：平放看二维，立起来看一维 -->

用 Cardputer-Adv 板上的 **BMI270** 做气泡水平。平放时显示二维气泡（俯仰 / 横滚）；立在键盘边或侧边时切成一维管。角度在 ±0.5° 内显示「水平」，并停掉告警。倾斜越大，滴声越密；刚进入水平时响一声。屏上还有角速度（°/s）和这次倾斜的峰值，**P** 清峰值。**Fn+[** / **Fn+]** 调背光，30 秒不动熄屏。

| 键 | 作用 |
|----|------|
| **G** | 把当前姿态当作零点 |
| **R** | 清除置零 |
| **P** | 清除倾斜峰值 |
| **Fn+[** / **Fn+]** | 暗 / 亮 |
| **S** | 开关告警音 |
| **-** / **=** | 小声 / 大声，共 0 到 10 级 |
| **?** | 帮助 |
| **Fn+BS** | 回基座 |

<!-- dev -->
桌面模拟没有 IMU，会慢慢晃动气泡。真机才读传感器。
<!-- /dev -->

```bash
./do.sh sim level
./do.sh sd fw level
```
