# 单词拼写固件

开机就是填空。词库是 `../alice/data` 里的小学词表（闽教版小学）。顶栏是中文释义：优先 `../alice/assets/data/library.json` 里带释义的词条，没有再取 `ecdict-meta.json` 的第一条。难度为易时底栏是音标，中和难时底栏空着。判对或判错时顶栏短暂换成「正确」或「不对」。7 个字母以内用大字，更长的词缩小。

| 键 | 作用 |
|----|------|
| 字母 | 填空。输满即判断 |
| **Enter / 空格** | 没填字时打开功能列表。有字则交卷，没填满也可以 |
| **BS / Esc / ←** | 删掉刚填的一个字母。`←` 是模拟器左方向键，板子上是 `Fn`+`H`。列表和帮助里这三个键回到上一页 |
| **`[` / `]`** | 难度：易约 1/3，中约 1/2，难是整个词 |
| **`\`** | 换词库 |
| **`,` / `.`** | 上一题 / 下一题。`Fn`+`K` / `Fn`+`J` 相同 |
| **`-` / `=`** | 音量 |
| **`?` / `/`** | 当前界面的帮助 |

```bash
./do.sh flash words
./do.sh sim words
```

词库或字体比源文件旧时会先问要不要生成。手动：`./do.sh gen-words`，再 `./do.sh gen-font`。
