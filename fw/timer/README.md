# 计时

倒计时，用摆放的姿势来控制：**把板子立在键盘那条长边上**（屏幕正对着你）就开始，**放平**就暂停。按键也能控制：Enter 开始或暂停。默认 25 分钟，K/J 在 1–60 分钟之间换（只在没走的时候能换，换了从头开始）。

到点后响 4 遍，标题显示「到点」，进度条变琥珀色。按任意键或者放平都能停掉铃声。再立起来，或者按 Enter，就从头再来一轮。

姿势要保持约 0.6 秒才算数，拿起来、碰一下都不会误触发。打开程序时已经立着，不会自己开始，要先放平再立起来。**G** 关掉姿态控制（标题右边的「立」字会消失），只用按键。时长、姿态开关和音量会记住。走表期间屏幕不熄。

| 键 | 作用 |
|----|------|
| 立起 / 放平 | 开始 / 暂停 |
| **Enter** | 开始 / 暂停 |
| **K** / **J** | 加长 / 缩短 |
| **R** | 回到开头 |
| **G** | 开关姿态控制 |
| **-** / **=** | 小声 / 大声 |
| **?** | 帮助 |
| **Fn+BS** | 回基座 |

桌面模拟没有陀螺仪，只能用按键。

```bash
./do.sh sim timer
./do.sh sd fw timer
```
