# 游戏

三个小游戏，方向键是键帽上印的箭头 `;` `.` `,` `/`，也可以用 WASD。

- **贪吃蛇**：吃到食物变长、加分，速度越来越快。撞墙或撞到自己就结束。P 暂停。
- **2048**：方向键把所有方块推向一边，相同数字合并。凑出 2048 后可以接着玩，直到推不动为止。
- **方块**：七种四格方块从上往下落，排满一行就消掉。`,` `/` 左右移，`.` 加速下落，`;`（或 W）顺时针转，Z 逆时针转，空格直接落到底。左右和下按住会连发。右边是下一个方块，半透明的影子标出会落在哪里。每消 10 行升一级，下落变快。一次消的行数越多分越高，加速和直接落下也加分。P 暂停。

游戏列表里显示各自的最高分，会记住。游戏中 BS 回列表，`-` `=` 调音效音量。配色跟随 Fn+T 主题。

```bash
./do.sh sim game
./do.sh sd fw game
```
