# 遥控
<!-- summary: 红外电视遥控，支持三星、LG、索尼、飞利浦 -->

用 Cardputer-Adv 板上的红外发射管（GPIO 44）当电视遥控器。**Tab** 换品牌，按键直接发。红外看不见，所以每发一次，板载灯会闪一下白光。

| 品牌 | 协议 | 载波 |
|------|------|------|
| 三星 | Samsung32（地址 0x07） | 38 kHz |
| LG | NEC（地址 0x04） | 38 kHz |
| 索尼 | SIRC 12 位（地址 1，连发 3 帧） | 40 kHz |
| 飞利浦 | RC5（地址 0） | 36 kHz |

| 键 | 发什么 |
|----|--------|
| P | 电源 |
| `-` `=` | 音量 − / + |
| `[` `]` | 频道 − / + |
| M / I / H | 静音 / 信号源 / 主页 |
| `;` `.` `,` `/` | 上 下 左 右 |
| Enter / BS | 确定 / 返回 |
| A | 各品牌的电源键依次发一遍 |

码表是各品牌电视最常见的那套默认码，同一品牌不同年份的机型可能不认。某个品牌没有的键会提示「没有这个键」（例如飞利浦 RC5 只收电源、音量、频道、静音）。要加品牌或改码，改 `codes.ts` 里的 `BRANDS`。

只能发，不能学：板上没有红外接收管。空调的遥控码是整包状态，不在这里。

<!-- dev -->
红外走 ESP32-S3 的 RMT 外设，驱动是本目录的 `ir.c`（用 ESP-IDF 5 以后的新 RMT 接口；Moddable 自带的 `pins/rmt` 还在用 IDF 6 已删掉的旧驱动）。桌面模拟没有红外，发送内容会打到 xsbug 日志里。
<!-- /dev -->

```bash
./do.sh sim remote
./do.sh sd fw remote
```
