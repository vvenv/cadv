# 设备

看这块 Cardputer-Adv 自己的信息。不联网，不改设置。

| 行 | 内容 |
|----|------|
| 芯片 / 修订 / 主频 | ESP32-S3、硅片版本、核数和当前主频 |
| 闪存 | 片上闪存容量 |
| 内存 | 片内堆剩余 / 总量 |
| PSRAM | 片外堆剩余 / 总量。没有就是「无」 |
| 最低 | 开机以来片内堆剩余的谷值 |
| 无线 / 蓝牙 | Wi-Fi STA 和 BLE 地址，从 eFuse 读，不打开射频 |
| 分区 | 当前在跑的槽。`ota_0` 是基座，`ota_1` 是从卡载入的程序 |
| 启动 | 上次复位原因 |
| 运行 | 这次上电后的时间 |
| 温度 | 片内温度，范围约 -10℃ 到 80℃ |
| 电池 | GPIO10，100k/100k 分压。电压是测量值；百分数按 3.30V–4.20V 线性估计。低于 2.80V 视为没接电池 |
| 键盘 / 姿态 / 声卡 | 开机探一次 I2C：TCA8418、BMI270、ES8311。探完才打开姿态和键盘 |
| SD | 卡上剩余 / 总量。没卡就是空 |
| 麦克 | 当前峰值，0 到 100 |
| 加速度 / 角速度 | BMI270 实时读数 |
| 亮度 | 当前背光档，1 到 4 |

内存、最低、运行、温度、电池每秒更新。其余开机读一次。

| 键 | 作用 |
|----|------|
| **K / J** | 上下 |
| **Fn+[** / **Fn+]** | 暗 / 亮 |
| **R** | 立即重读 |
| **?** | 帮助 |
| **Fn+BS** | 回基座 |

```bash
./do.sh sim info
./do.sh sd fw info
```
